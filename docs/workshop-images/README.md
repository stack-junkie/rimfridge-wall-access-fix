# Workshop Images

All images in this folder are 1280x720 exports. The source screenshots keep their original aspect ratios and are padded with black bars where needed.

## Recommended Use

- Primary preview: `04-hero-preview-1280x720.png`
- Steam upload fallback if PNG upload fails: `04-hero-preview-1280x720.jpg`
- Mod preview copied into `mod\About\Preview.png`

## Image Notes

- `01-fridge-close-1280x720.*`: close-up fridge/content view. Useful as a secondary detail image.
- `02-room-and-fridges-1280x720.*`: busy room view with wall fridges. Secondary image only.
- `03-fridge-icon-not-recommended-1280x720.*`: stop for hero use. It is too cropped and blurry for a Workshop preview.
- `04-hero-preview-1280x720.*`: selected hero image with text overlay.
- `05-pawn-lineup-wall-fridges-1280x720.*`: pawn lineup and wall-fridge context. Good secondary proof image, but too busy for the primary thumbnail.
